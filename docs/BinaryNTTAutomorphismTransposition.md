# Binary-NTT automorphism KDM: transposition case

This module formalizes the finite core of
`sketch/automorphism_kdm_transposition_proof.tex`.

## Scope

The result concerns an NTT automorphism that swaps two coordinates and fixes
all remaining coordinates. It does not prove security for a cycle whose length
grows with the ring degree or for a polynomial family of unrelated
automorphisms.

For a Binary-NTT secret `S`, one automorphism-key row is

```text
(A, A*S + E + g*sigma(S)).
```

In split NTT coordinates this is a binary-secret structured-LWE row with
operator

```text
diag(a) + diag(g) P,
```

where `P` is the transposition matrix.

## Checked algebra

The formalization proves:

- the exact automorphism-key phase;
- decomposition of a weighted transposition into a fixed diagonal component
  and two public one-coordinate shifts;
- impossibility of representing a nonzero moved-coordinate term by one public
  diagonal/ring multiplier on every binary secret;
- exact absorption of the fixed-coordinate component by ordinary mask
  translation at the surrounding game layer.

## Checked insertion argument

For a joint hidden-secret/public-view sampler, a response function `d`, and a
public shift `tau`, define

```text
q(y) = d(y+tau)-d(y)
m(y) = q(y)/2.
```

Lean proves the exact identity

```text
insertionGap = E[m(Y)] - E[(-1)^bit * m(Y)].
```

It follows that insertion of one hidden bit is bounded by one ordinary-view
response gap plus one parity correlation.

After the first insertion, the response under the inserted bit is decomposed
into its even and odd parts. The correlation with the second bit is exactly
the sum of two ordinary-view correlations:

```text
correlation(bit_v after inserting bit_u)
  = correlation(bit_v, evenPart)
  + correlation(bit_u xor bit_v, oddPart).
```

This is the rigorous form of the manuscript’s “second bit remains hidden”
argument.

## Quantitative transposition theorem

Let `epsilon` bound the necessary ordinary-view tests and let `delta` bound
the nonzero parity correlations generated by the two insertion steps. The
formal theorem proves

```text
abs(two-coordinate insertion gap) <= 3*epsilon + 4*delta.
```

The theorem lists the seven concrete response/parity bounds used in the
proof. This avoids quantifying over all real functions, which would incorrectly
turn a computational statement into statistical security. An eventual PPT
instantiation supplies an `allowed` closure proof for exactly those derived
responses.

## Parity hiding

The manuscript converts a predictor with correlation `rho` into an ordinary
Binary-NTT RLWE distinguisher with advantage `rho^2/2`, using two row blocks,
exact XOR secret rerandomization, and a product-sign test.

The arithmetic consequence is checked:

```text
ordinaryDecisionAdvantage <= eta
  -> abs(rho) <= sqrt(2*eta).
```

The TeX proof contains a duplicated predictor/character factor in one displayed
expectation. The formal identity uses the intended expression with one factor;
the surrounding derivation is consistent with that correction.

`ParityHidingCertificate` records the exact doubled-game identity. Its
`advantage_eq` field is not a hardness assumption.

The concrete batch XOR map is installed. Lean proves pointwise that it
changes the hidden secret from `s` to `s xor z`, preserves every error
coordinate, is an involution on the complete public row batch, and preserves
the exact uniform endpoint.

The doubled-row bridge is now closed. `actualParityHiding_advantage_eq_sq_div_two`
proves that the same public algorithm on ordinary real and uniform two-block
challenges has advantage exactly `rho^2/2`.
`splitParityHiding_advantage_eq_sq_div_two` instantiates this theorem with the
concrete split-ring channel, `xorView`, arbitrary complete error-vector
sampler, and arbitrary row family. It proves:

1. the two honest blocks share one uniformly sampled Binary-NTT secret;
2. masks and errors are independent between blocks conditioned on that secret;
3. independent uniform XOR masks rerandomize both blocks exactly;
4. the real product-sign mean is `rho^2`;
5. the uniform twisted blocks have mean zero because every nonzero parity is
   balanced; and
6. the resulting Boolean decision advantage is `rho^2/2`.

Consequently, no parity-hiding certificate remains to be supplied for the
transposition theorem. The unrestricted-cycle Fourier loss remains exponential
and is intentionally not claimed. A final asymptotic/PPT wrapper may package
the finite bounds into the project’s negligible-function interface, but it
contains no further cryptographic premise.
