# Hierarchical staged descent for BGV

`BGVHierarchicalStagedDescent.lean` formalizes the algebraic core of
`sketch/proof-common-fixed-secret-etc.md`.

## Stronger simplification found during formalization

Let an upper and lower secret satisfy

```text
S = H*embed(T) + C,
```

where `H` is a public unit and `C` is public completion data. Define

```text
Desc(A,B) =
  (Even(A*H), Even(B-A*C)).
```

Lean proves for every ciphertext, without a well-formedness premise,

```text
phase_T(Desc(A,B)) = Even(phase_S(A,B)).
```

Therefore a staged hierarchical construction does not need an automorphism
evaluation key to perform this projection. The normalized trace circuit in the
sketch is valid but redundant for descent; omitting it removes its key-switch
noise and its circular/KDM security object.

## Public lift

For a lower ciphertext `(A',B')`, the deterministic lift is

```text
A_tilde = embed(A')*H^(-1)
B_tilde = embed(B') + A_tilde*C.
```

Its upper-secret phase is exactly the embedding of the lower phase. Adding an
ordinary zero encryption under the upper key rerandomizes the mask and adds
only that zero row's error. Lean proves the phase identity and proves that
translation by the fresh uniform zero-row mask gives an exactly uniform upper
mask.

No encryption of an upper secret under a lower secret, or conversely, appears
in this lift.

## Uniform descent mask

`SplitDescentTower` exposes the additive even/odd coordinate equivalence.
Multiplication by `H` followed by this split is a bijection. Projecting its
first component maps a uniform upper mask to an exactly uniform lower mask.

The executable negacyclic even/odd distribution and error transport remain
the already checked `EvenSecretReduction` results.

## Optional normalized trace

The module also checks the manuscript's trace presentation. If an
automorphism-key operation has phase

```text
sigma(phi) + 2*kappa,
```

then trace, descent, and multiplication by `1/2` have lower phase

```text
Even(phi) + Even(kappa).
```

Thus the explicit factor two prevents multiplication of the narrow
key-switch error by the modular representative of `1/2`. Unit scaling of a
complete RLWE row is proved bijective, scales the phase exactly, and preserves
the uniform endpoint. This optional route is not needed by the simpler public
descent construction.

## Hierarchy and accounting

Successive Binary-NTT completions are composed into one equivalence

```text
(bottom secret, all completion coins) <-> top Binary-NTT secret.
```

Consequently the top secret is exactly uniform marginally, and the hierarchy
has exactly the same total number of binary choices as a top secret. The
recursive bottom-sample count and the factor-two comparison-pool count are
also defined and checked.

## Security boundary

The public descent/lift construction removes the local automorphism-key
security problem. Public-key and zero-encryption rows across the hierarchy can
be generated by recursive use of the exact even-secret RLWE compiler.

This still does not give an end-to-end scalar BGV bootstrap. Descent must stop
at a bottom degree where ordinary Binary-NTT RLWE remains secure. A terminal
refresh or scalar-extraction procedure at that degree is still required. If
that procedure publishes a secret-dependent same-key object, its security is
a new cryptographic obligation.
