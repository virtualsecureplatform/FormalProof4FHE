One-secret-key LWE-GSW: exact target and first research filter
===========================================================

Objective
---------
Construct a correct, repeatably bootstrappable FHE scheme with one secret key,
without an independent 1-circular-security assumption or an acyclic schedule of
independent keys. Eventually prove both security and correctness in Lean.
The user confirmed on 2026-10-07 that ordinary LWE alone must be the
computational foundation. Binary-secret hardness, leakage security, quadratic
KDM, and any additional hardness conditions must be reduced to that premise,
not retained as independent assumptions. An obfuscation assumption or an
independently assumed SIS/leaky-LWE problem is not an acceptable endpoint.
This document records progress toward that objective; it does not claim it has
been achieved.

Fixed first candidate
---------------------
Use the mod-q matrix presentation of GSW, with a binary secret s in {0,1}^n.
Start with private-key fresh sampling, not public-key subset-sum sampling.
For an underlying LWE column (a, b = <a,s> + e), add the gadget column for
message mu. With decryption vector (1,-s), the two kinds of column are:

  body:  a' = a,                 b' = b + mu*g_k;
  mask j: a' = a + mu*g_k*e_j,   b' = b.

Equivalently, with uniform a' and unchanged encryption-error distribution:

  body:   b' = <a',s> + e + mu*g_k;
  mask j: b' = <a',s> + e - mu*g_k*s_j.

A same-key refresh tape encrypting each s_i therefore contains all the terms
-g_k*s_i*s_j and the body terms g_k*s_i. The full tape has n*(n+1)*w LWE
columns for a gadget of length w. For binary secrets s_i*s_i = s_i, so the
diagonal and body messages are affine. The remaining off-diagonal messages
are quadratic.

Checked algebra and distribution targets are in LWE/GSWSelfKey.lean:
  freshTranscript_eq_normalized: exact column algebra;
  freshTranscript_phase: exact phase and unchanged original error;
  freshView_evalDist: equality of complete fresh and normalized distributions,
    retaining arbitrary secret-dependent auxiliary information;
  selfKey_body_phase and selfKey_mask_phase: actual full-tape messages;
  binary_selfKey_diagonal_phase: diagonal collapse;
  quadraticBits_injective and recover_from_offDiagonal: exact-leakage barrier.
  binaryProduct_not_affine: off-diagonal products have no fixed affine form.

LWE/GSWOperations.lean connects the transcript to the rectangular ciphertext
matrix with decryption vector (1,-s). It proves that fresh matrix encryption
has exactly the sampled error and establishes the addition and multiplication
identities:

  e_add = e1 + e2;
  e_mul = e1 * D2 + mu1 * e2, provided G * D2 = C2.

LWE/GSWGadget.lean now supplies the executable rectangular digit matrix from
the existing scalar base decomposition, proves G*D(C)=C for every ciphertext,
and bounds every centered digit by base-1. It implements multiplication and
NAND with nearest-codeword decryption. If M=(n+1)*levels*(base-1), the
worst-case bit-product error bound is M*B_left+B_right. A right-associated
chain of L bit ciphertexts with noise at most B has noise at most L*M*B.
These deterministic unsigned-digit bounds are weaker than AP14's randomized
subgaussian bounds, but they retain polynomial chain growth without needing
independence between inputs.

The equality allows an arbitrary joint error sampler independent of the
secret, challenge, and auxiliary sampling. It does not model correlations
created by public-key reuse. The challenge permutation depends on the secret
message and therefore is not an ordinary-LWE security reduction.

Concrete same-key cyclic lookup component
----------------------------------------
LWE/GSWAccumulator.lean implements a vector of p GSW ciphertexts, one for
each index in ZMod p. Coefficients and GSW ciphertexts live at a potentially
much larger modulus Q. For a small-modulus input (a,b), initialize a zero-error
indicator at index b. With a GSW control C_i encrypting secret bit s_i,
update every coordinate x by

  acc'_x = CMux(C_i, acc_(x+a_i), acc_x);
  CMux(C,X,Y) = Y + C*D(X-Y).

The ideal indicator moves from v to v-a_i when s_i=1 and stays at v when
s_i=0. Both branches are encrypted under the same key. The exact CMux error is

  e_C*D(X-Y) + (if s_i=1 then e_X else e_Y).

Consequently each step costs M*B_key plus the previous accumulator bound.
After n steps the indicator is at b-<a,s> with error at most n*M*B_key.
For any public Boolean function f:ZMod p->Bool, sum the coordinates for
which f(x)=1. The resulting GSW ciphertext encrypts f(b-<a,s>) with error
at most

  B_out = p*n*M*B_key = p*n*(n+1)*levels*(base-1)*B_key.

This bound is independent of the input sample's noise and mask sizes; input
noise still matters for whether f(b-<a,s>) equals the desired input message.
The evaluator accepts only public mask coefficients, body, lookup function,
and encrypted controls. Secret bits occur only in the correctness statements.
freshBootKey actually encrypts every bit under that same binary secret,
and decrypt_refresh_freshBootKey proves output decryption under it when
2*B_out is less than the selected gadget codeword distance. No independent
secret, acyclic schedule, ring-LWE assumption, or security axiom is used.

StoredCiphertext and StoredAccumulator hold explicit finite vector data.
runStored and refreshStored return these data types; their function views
are used by the mathematical proofs. Every accumulator stage and every
ciphertext matrix entry are materialized before the next stage reads them. Keeping only recursively nested function closures would
recompute both CMux branches and earlier matrix products; it would not be
an adequate implementation for a polynomial-time refresh. The storage/view
identities are formally proved. Inspection of generated code checked that
each recursive stage returns data before the next stage reads it; functions
that merely return a snapshot-reading closure were rejected after the compiler
expanded them and rebuilt their tables at every read. A formal operation-count bound is still to
be added. With p polynomial, the stored stages give a polynomial-sized
arithmetic computation; this is a vector version of the encrypted cyclic
arithmetic idea in AP14, rather than its optimized CRT representation.

Public scaled reduction and repeatable gate correctness
-------------------------------------------------------
LWE/GSWModulusSwitch.lean supplies the actual public coefficient map

  down(x) = floor(x.val/d) mod p, for Q=d*p.

The proof-only additive embedding up:ZMod p -> ZMod Q multiplies by d.
It scales centered distance exactly, including the half-modulus tie. For
binary secret s, rounding the mask and body gives the exact phase law

  up(b_down - <s,a_down>) = b - <s,a> - residual;
  |residual|_Q <= (n+1)*(d-1).

If the source phase is within E of up(code_bit), then the reduced phase has

  d*distance_p(phase_down, code_bit) <= E+(n+1)*(d-1).

Consequently 2*(E+(n+1)*(d-1)) < d*distance_p(0,code_one) guarantees the
same decoded bit. This is scaled floor rounding, not plain reduction modulo
a divisor: the latter can erase a Q/2 bit codeword. No statistical independence
between the source mask, source error, or rounding residuals is needed.

LWE/GSWBootstrap.lean extracts the selected public body-gadget column,
rounds its body and mask, and feeds them into refreshStored using the public
nearest-codeword lookup. bootstrapStored returns actual ciphertext data;
bootstrap is its mathematical matrix view. The source phase identity proves
that extraction preserves the original secret. noiseBound_bootstrap and its
freshBootKey corollary derive the correct refreshed message from the source
noise bound and the explicit rounding margin. No secret enters the evaluator.

LWE/GSWBootstrapParameters.lean discharges both margins for one deliberately
conservative polynomial-modulus family. At dimension n, set

  s=n+1, b=64*s, levels=16;
  Q=b^16, p=b^3, d=b^13;
  code_one=b^2 in the lookup, selected gadget=b^15 in Q;
  B_key=s^2, M=16*s*(b-1);
  B_out=p*n*M*B_key, E=(M+1)*B_out.

The checked inequalities include E<=d, the strict rounding margin above,
2*B_out<distance_Q(0,b^15), and B_out<=E. The proof does not require a
half-modulus gadget codeword: the codeword distance is b^15. The selected
level is 15 out of sixteen. noiseBound_refreshedNand proves that two inputs
bounded by B_out yield a NAND/refresh output bounded by the same B_out;
decrypt_refreshedNand proves its decoded output. Thus the same controls and
unchanged secret can support arbitrary repetitions of this gate operation.
The family is not optimized. The modulus is polynomial of degree sixteen
and the lookup has polynomial size of degree three. Its bit length therefore
grows logarithmically in n; feasibility was not obtained by making Q
exponential in the secret dimension.

Shared circuits and public input encryption
------------------------------------------
LWE/GSWCircuit.lean represents a circuit by an indexed sequence of NAND gates.
Each gate refers to two existing wires, including the same wire twice or an
earlier intermediate used by several later gates. runStored returns a vector
of concrete wire data; it evaluates the preceding program once, reads both
inputs from that data, computes one output, and pushes that output. The
runStored_rel theorem transfers a gate-preserved relation to all wires.
noiseBound_evaluateWires instantiates it with the checked GSW invariant,
and decrypt_evaluate proves an arbitrary selected output equals the Boolean
program semantics. Every wire uses the unchanged secret and control table.
The output matrix has sixteen*(n+1)^2 coefficients independently of circuit
depth, fanout, and size.

runCounted_eq proves the instrumented evaluator returns the same table and
counts precisely the program's number of gates. This counts gate-operation
invocations, not scalar arithmetic or machine bit operations within a refresh.
The executable implementation accepts explicit public parameters; the theorem
instantiates the concrete family. This avoids forcing huge modulus expressions
through dependent-type reduction while compiling specialized evaluator wrappers.
Generated C inspection verifies one preceding-program call, two stored array
reads, one operation call, and one array push in each recursive branch.

LWE/GSWPublicKey.lean adds a stored public-key table. Given uniform challenges
A and original errors e, freshPublicKey materializes

  PK = [ <s,A>+e ; A ], with vecMul(1,-s, PK)=e.

For binary selection matrix R and input bit mu, public encryption returns
stored data for

  C = PK*R + mu*G;
  noise(C,mu) = e*R.

Every selection coefficient has centered magnitude at most one, so m
public-key samples with error bound B_key give input noise at most m*B_key.
This bound allows arbitrary correlations, including errors reused across
columns and across different encrypted inputs. Public encryption receives
only stored public-key data, selection coins, and the input bit; it receives
no secret. Private key generation completes the public-key data before
returning it, rather than returning a closure that computes its body from s.

The selected sample count m=256*(n+1)^2 satisfies m<=p*n*M for every n>0.
Therefore m*B_key<=B_out. This is a correctness-budget theorem; a complete
leftover-hash/ordinary-LWE security argument for this sample count is still
required. storedFreshBootKey materializes the original private fresh controls
under exactly the same bits. encryptInputsStored materializes public input
ciphertexts. decrypt_evaluate_freshPublicKey proves whole-circuit output
correctness for these actual generators given bounds on the original public-
key and control errors. It leaves no parameter-margin or correct-lookup premise.

LWE/GSWSampling.lean now supplies the actual probabilistic key generation
and public input encryption. sampleKeyDraws draws independent scalar errors,
then an independent uniform tuple containing one binary secret and all public
and control masks. materialFromDraws completes the public tables privately.
generateKeys returns that material without retaining the original error vector;
public encryption draws independent uniform binary column-selection coins.
correctnessExperiment composes these algorithms with evaluation and decryption.

probEvent_sampleKeyDraws_errors proves that every event depending on the
original errors has exactly the IID product probability. GoodDraws means that
all originally generated errors have centered magnitude at most B_key.
probEvent_goodDraws gives its exact probability as the scalar good probability
to the power of the number of key errors. The number is

  K = m + n*(n+1)*levels <= 272*(n+1)^2.

For n>0, decrypt_from_goodDraws transfers the deterministic circuit theorem
to the actual generated key material for every choice of encryption coins.
Thus correctness_failure_le_dimension_bound proves, in the actual operational
probabilistic experiment,

  Pr[incorrect output] <= 272*(n+1)^2 * Pr[|scalar error|_Q > (n+1)^2].

This bound has no circuit-depth, gate-count, fanout, or input-count factor.
Key errors are reused by public encryption and controls; the deterministic
bounds already account for every such reuse. GoodDraws is a proof event,
not a rejection-sampling condition used by key generation.

The scalar error sampler remains explicit. This does not prove an arbitrary
sampler secure or its tail negligible. Remaining full-construction work includes
formal polynomial bit-operation costs for the concrete finite sampler and
evaluator, ciphertext bit serialization, and the ordinary-LWE security reduction.
The ideal Gaussian tail, computed finite Gaussian weights, and their normalized
negligible-TV certificate are proved as described below. Strict polynomial-time
random-bit implementation and full arithmetic cost bounds are not yet proved.
The joint public view includes the zero-message public-key
samples together with the masked quadratic self-key tape. Their joint security,
including the required binary-secret and noise-distribution bridges, must be
derived from ordinary LWE alone. These correctness results do not establish
hardness of that view or fulfill the complete FHE objective.

Quantitative Gaussian tail and the executable-sampler boundary
--------------------------------------------------------------
Probability/DiscreteGaussianTail.lean proves the scalar tail analytically
using the repository's exact Gaussian convention, weight exp(-z^2/(2*s^2)).
For any positive integer width s, the centered normalization is at least
its weight at zero, which is one. For k>=0, the positive mass at s^2+k+1 is
at most exp(-s^2/2)*exp(-k). The geometric sum is at most two; symmetry gives

  Pr[|integer error| > s^2] <= 4*exp(-s^2/2).

The exact signed-tail decomposition and event-to-mass equality are proved.
Centered modular magnitude never exceeds the original integer magnitude,
so the same bound holds for the ideal Gaussian reduced modulo any Q>0.

The generic event/TV theorem and exact finite-table denotation transport this
bound to the actual executable sampler in a checked TicketTable.Certificate.
There is one copy of the scalar approximation error delta:

  Pr[|implemented scalar error|_Q > s^2] <= 4*exp(-s^2/2) + delta.

LWE/GSWGaussianCorrectness.lean specifies the ideal scalar standard deviation
s=n+1 and composes this bound with the actual probabilistic GSW experiment.
Its explicit whole-circuit bound is

  272*(n+1)^2 * (4*exp(-(n+1)^2/2) + delta).

The Gaussian term is negligible by a proved geometric majorant 2^(-n).
Polynomial multiplication preserves negligibility. For a family of checked
finite certificates with negligible scalar approximation bounds, the actual
whole-circuit failure probability is negligible, even with varying input
counts and arbitrary finite circuit programs. The finite n=0 case is handled
by an envelope greater than one, without changing the correctness experiment.
For n>0, the bound comes from the established deterministic noise invariant.

This closes the ideal analytic tail calculation. Generic TicketTable stores
each ticket as an explicit repeated entry; making the denominator exponentially
large can make that representation exponentially large. The existing
noncomputable rounded certificate is an existence/approximation result, not an
efficient construction. The compressed representation described next removes
this storage problem. Computable Gaussian weights with checked pointwise error
and their normalized negligible-TV certificate are supplied below. Full
bit-operation cost proofs and random-bit implementation remain needed; no
complete strict-PPT sampler theorem is asserted here. The binary-secret and
ordinary-LWE joint-view security bridges remain separate obligations.

Compressed weighted sampling and its correctness bridge
-------------------------------------------------------
Probability/WeightedSampler.lean stores a list of (outcome, natural weight)
pairs with positive total weight W. The operational sampler makes one uniform
Fin(W) oracle query, then walks the list: return the current outcome if the
ticket is below its weight, otherwise subtract that weight and continue.
Zero weights are skipped, duplicate outcomes add their weights, and a valid
ticket never reaches the fallback. No repeated ticket list is allocated.

The exact output probability is outcomeWeight/W. The decoder's returned value
matches the proof-only expanded TicketTable; its counted version inspects at
most k entries for a list of length k. If each stored weight is at most 2^p,
then W < 2^(p+k), bounding the ticket bit length by p+k. These are formal
representation and entry-count bounds, not a complete bit-operation theorem
or an implementation of the uniform oracle using random bits.

A compressed Table.Certificate checks TV distance directly from the weighted
probabilities. Its proof-only expanded adapter denotes exactly the same sampler.
GSWGaussianCorrectness transports the previous Gaussian failure envelope to
this actual compressed sampler with no additional approximation error. A
negligible certified scalar error implies negligible whole-circuit failure.
For positive secret dimension, correctness_failure_eq_zero_compressed_bounded
also proves failure probability exactly zero whenever all stored scalar errors
have centered magnitude at most (n+1)^2. This support theorem needs no Gaussian
certificate; deriving the security of a chosen bounded approximation still
requires the ordinary-LWE noise-distribution bridge.

The executable smoke diagnostic checks all eight tickets of a small table,
including zero weights and duplicate outcomes, and its exact 5/8 probability.
A four-entry table with W=2^256+5 checks the decoder at four boundary tickets
without allocating W entries. It checks large-integer decoding, not execution
of a random draw from that enormous ticket space. Generated C contains the
subtraction loop and one uniform query; proof-only expanded tables have no
runtime symbols. The computed Gaussian weights below add concrete data and
pointwise approximation proofs, followed by a normalized negligible-TV
certificate. Random-bit sampling cost, ciphertext serialization, evaluator
bit-operation costs, and full joint-view security remain unfinished.

Computed Gaussian integer weights
---------------------------------
Probability/GaussianIntegerWeights.lean supplies actual computable table data.
For positive width s and a stored integer |z|<=s^2, set m=s^2+1 and
x=z^2/(2*s^2*m). The argument is in [0,1]. With precision p, compute

  T_p(x) = sum_(i=0)^(p+1) x^i / i!,
  rho(z) = (1 / T_p(x))^m,
  weight(z) = floor(2^p * rho(z)).

All operational calculations use rational/natural arithmetic. No real
exponential, ideal probability, or analytic certificate is evaluated by the
generator. T_p(x)>=1 and the reciprocal lies between exp(-x) and one.
Mathlib's proved exponential remainder, the elementary bound
2^(p+1)<=(p+2)!, and a unit-interval power error inequality give

  |weight(z)/2^p - exp(-z^2/(2*s^2))| <= (s^2+2)/2^p.

Natural flooring contributes at most one dyadic unit. The checked weight at
zero is exactly 2^p, all weights are at most 2^p, and weight(-z)=weight(z).
The generator stores all 2*s^2+1 integers through the squared-width cutoff;
weights equal to zero remain harmless stored entries. The denominator W is
positive because of the zero entry and has at most p+2*s^2+1 binary digits.
At s=n+1 and p=s^2, the pointwise error is proved negligible and W is below
2^(3*s^2+1). The representation and precision grow polynomially; a formal
machine-bit complexity theorem for the arithmetic and random source is still
required.

The modular table maps the stored outcomes to ZMod Q and retains their
weights. Its actual ProbComp sampler equals the modular image of the integer
sampler, including when different integers collide modulo Q. Modular reduction
never increases centered magnitude. GSWGaussianCorrectness now proves that
using these generated errors in the actual public-key/one-secret-key control
generation, input encryption, and circuit experiment gives failure probability
exactly zero at positive secret dimension, for arbitrary precision, input
coins, circuits, and output wires. This correctness theorem makes no scalar
approximation premise.

The error bound above compares weight(z)/2^p with an UNNORMALIZED Gaussian
weight. The actual probability is weight(z)/W, and the ideal Gaussian also
has its own normalization and unbounded support. The complete comparison is
now proved as described next; negligible pointwise error alone is not used
as a substitute for a distribution theorem.

Normalized Gaussian TV certificate for the generated sampler
------------------------------------------------------------
Probability/NormalizationTV.lean proves a generic PMF normalization inequality:

  TV(target,actual) <= sum_z |target(z) - c*actual(z)|.

The PMF real masses are summable and sum to one. Consequently the sum of
pointwise discrepancies also bounds |1-c|. The triangle inequality for L1,
followed by division by two, accounts for the complete normalization change.
The theorem applies to countable infinite-support distributions as well as
finite ones; there is no assumed normalization certificate.

Probability/GaussianSamplerTV.lean instantiates c=W/(2^p*Z), where Z is the
ideal Gaussian normalizer. It proves the exact count law of every generated
integer outcome from the unique cutoff list. The scaled actual PMF is the
computed weight divided by 2^p*Z inside the cutoff and zero outside. Inside,
Z>=1 bounds the discrepancy by (s^2+2)/2^p per stored integer. Outside, the
discrepancy is exactly the ideal Gaussian's tail probability. The finite
error sum and previously proved Gaussian tail therefore give

  TV(generated table, ideal Gaussian) <=
    (2*s^2+1)*(s^2+2)/2^p + 4*exp(-s^2/2).

This is a checked Lean theorem, including both normalizers and truncation.
The exact generated modular PMF is the mapped integer PMF. Data processing
supplies the same bound for every positive coefficient modulus Q, with no
Q-size factor. modularCertificate contains the actual computable table,
an explicit ofReal bound, a proved finite bound, and a proved validity field.
It assumes only positive width/modulus; no pointwise error or TV hypothesis
is left for a caller to supply. The certificate wrapper is noncomputable
because its proof-bound uses a real exponential, but its table field is proved
identical to the already computable modularTable. The operational sampler
continues to use that raw table, without evaluating any ideal probability.

For s=n+1 and p=s^2, approximationBound_family_negligible proves the COMPLETE
TV envelope negligible by polynomial closure and the Gaussian tail theorem.
GSWGaussianCorrectness now constructs generatedScalarCertificate, proves its
bound negligible, and proves the actual generated scalar's TV to idealScalar
negligible. correctness_failure_generated_negligible connects the concrete
raw table to the actual key-generation/public-encryption/circuit experiment
without an approximation-certificate premise. It retains the dimension-zero
experiment and allows varying input counts, circuits, and output wires. The
stronger exact zero-failure result at every positive secret dimension still
holds from bounded support.

The complete joint-view comparison described next accounts for every original
scalar key draw and preserves the common one-key correlations. Strict random-bit
sampling, formal arithmetic and evaluator bit costs, ciphertext serialization,
the binary-secret bridge, and computational security of the full real same-key
view remain open. Gaussian approximation alone does not hide the quadratic tape.

Complete same-key Gaussian replacement and game transfer
--------------------------------------------------------
Probability/FiniteProductTV.lean proves extended TV for an independent finite
product is at most the sum of scalar TV distances. The scalar reference may
have infinite support: no executable ideal sampler is assumed. liftM_sampleIID
identifies the actual finite sampler with that precise product PMF. Shared
randomized continuations contract TV, even when they retain or inspect all
original data.

LWE/GSWNoiseComparison.lean defines referenceDraws and referenceKeys by changing
ONLY the scalar error law. Both sample the same uniform seed containing the one
binary secret, every public-key mask, and every control mask. The original error
vector has K=m+n*(n+1)*levels coordinates. The real materialization function
constructs the actual stored public key and all actual stored controls under
that same secret. The module proves

  TV(actual complete key material, reference complete key material)
    <= K * TV(actual scalar error, reference scalar error).

This is a comparison of the complete correlated laws, not a comparison of
individually secure ciphertexts. The mathematical key material retains even the
client secret, which makes the statistical comparison stronger. publicView
projects it to exactly the public key and complete controls without exposing
the secret. No security game here grants a secret to its adversary.

For the generated Gaussian family, K<=272*(n+1)^2 and the previously proved
scalar certificate has no unproved error premise. family_keys_etvDist_le gives
this closed envelope, and family_keys_etvDist_negligible proves it negligible.
The bound includes dimension zero. A shared randomized observation of the keys
has the same bound; no additional input-count, query-count, gate-count, depth,
or fanout multiplier is introduced by processing already generated material.
An actual security game's kernel must still implement the intended public view
and legal challenge generation; an arbitrary kernel is only a general TV lemma.

For Boolean games, booleanAdvantage is the absolute gap between the two true-
output probabilities. Its toReal theorem identifies the usual real gap. Applying
one shared kernel for each challenge branch yields

  implemented advantage <= ideal reference advantage + 2*joint TV envelope.

family_advantage_le_reference proves this statement for the concrete sampler.
family_advantage_negligible_of_reference transfers an independently established
negligible reference advantage. Its hypothesis is explicit: computational
security of the Gaussian reference has NOT been established. These lemmas
remove the finite-Gaussian approximation obligation from a future reference-game
security proof; they do not replace the missing ordinary-LWE reduction.

Exact public binary-secret randomization
----------------------------------------
LWE/GSWBinaryRandomization.lean studies the entire masked view directly. For
any layout of zero, linear, and quadratic monomials, choose a public flip
u in {0,1}^n and put d_i = 1-2u_i, t_i = d_i*s_i+u_i = s_i xor u_i.
For a column with weight w and monomial f, define lambda = 1 for f=0,
d_i for f=s_i, and d_i*d_j for f=s_i*s_j. Define delta=0 for zero/linear
rows and delta = w*(u_j*e_i+u_i*e_j) for a quadratic row. The public
constant c is the weighted monomial evaluated at u. Transform each column:

  a'_r = lambda*d_r*a_r - delta_r;
  b'   = lambda*b + <u,a'> + c.

Expanding the shifted monomial gives, exactly:

  b' = <t,a'> + w*f(t) + lambda*e.

This includes diagonal quadratic products, all actual gadget weights, and
zero-hint rows used for ordinary fresh samples or a privately sampled public
key. Both the mask transformation and the complete transcript transformation
have explicit public inverses. A symmetric IID error law is invariant under
all the column sign flips. Thus, for every fixed secret and flip, the
transformed real view has exactly the sampler law for the flipped secret.
The same public transformation preserves a completely uniform transcript.
Uniform flips produce a uniform fresh binary secret. The flips are a
proof-experiment coupling; the intended construction still uses one
operational secret key throughout encryption and refresh.

The checked declaration viewRandomization instantiates the existing
AuxiliaryInput.SearchToDecision.ViewRandomization interface with error=0;
its narrow and wide samplers coincide. signal_selfKey_eq_phaseMessage
identifies this monomial layout with the entire actual n*(n+1)*w GSW
self-key phase, including the negative weights on mask columns. There is
no noise flooding or added cryptographic premise in this randomization step.

This is a search-to-decision ingredient, not an ordinary-LWE reduction.
The input ALREADY contains the quadratic hint tape, and the output retains
it under a randomized secret. Ordinary-LWE-to-search hardness of the complete
masked view and an efficient quantitative decision-to-search reduction remain
unproved. An arbitrary secret-dependent auxiliary object cannot be retained
unchanged during this key flip; it must have its own compatible transform,
or be represented by jointly transformed rows with the required error law.
Public-key reuse can also correlate row masks/errors beyond the fresh sampler
modeled here. The result does not claim a new general search-to-decision theorem
or a novel cryptographic hardness result.

Polynomial KDM amplification and the GSW feature-closure test
--------------------------------------------------------------
BGK11 (Brakerski--Goldwasser--Kalai, TCC 2011, full ePrint 2009/485) has now
been added to refs/kdm/BGK11.pdf, with catalog, bibliography and checksum.
Section 6 proves polynomial KDM security from standard decisional LWE for
an ACPS-based encryption law. Its one underlying binary key x is expanded
into gamma_{n,d}(x), the squarefree monomials up to degree d. The public LWE
key and decryption vector use that expansion. The stated reduction has its
own parameters: q=p^2, sufficiently large prime p, source dimension roughly
(n-omega(log lambda))/log q, and a negligible source/target noise ratio.
It is not an instantiation at the current GSW family parameters, and its
ciphertext-generation law is not the current GSW matrix law.
Primary full version: https://eprint.iacr.org/2009/485
Publisher metadata: https://doi.org/10.1007/978-3-642-19571-6_13
The publisher chapter is subscription content, but the complete full ePrint
was retrieved and parsed; no manual download is needed for BGK11.

This suggests testing a particular approach: enlarge the GSW decryption key
with secret features phi_j(x), then absorb all self-key body and mask messages
as affine functions of that SAME enlarged key. At gadget weight one, the
body phase contains x_i and the mask phase contains -x_i*phi_j(x). Degree-d
monomials produce degree-(d+1) products when a missing bit is introduced;
raising the truncation degree also changes the decryption vector.

LWE/GSWFeatureClosure.lean now proves a general exact obstruction to that
approach. Let V be the linear span of the constant and all phi_j as functions
on the complete n-bit cube. If all body messages and all mask products belong
to V, multiplication by every bit coordinate maps V to itself. Repeatedly
multiplying by x_i or (1-x_i) constructs every point indicator. Their scalar
linear combinations construct EVERY function on the cube, so V is the full
function module. Its rank is 2^n, requiring

  number of nonconstant decryption features + 1 >= 2^n.

The proof uses arbitrary features, not just monomials, and any nontrivial
commutative coefficient ring, including composite ZMod moduli. It needs no
field hypothesis or cryptographic assumption. For a smaller feature vector
whose body phases are affine, exists_nonaffine_mask_product proves some
mask product is outside its affine span. Negation does not change membership.
controlPhase uses the existing GSWSelfKey.phaseMessage definition for a
weight-one gadget column; controlPhase_body and controlPhase_mask identify its
exact functions. control_phase_feature_count_ge applies the capacity bound
directly to these actual GSW body/mask messages.
The constant represents the compulsory leading component of the GSW
extended decryption vector. Ordinary affine absorption uses global scalar
coefficients; secret-dependent coefficients do not meet this span condition.

This restriction applies to EXACT affine representation of all phases under
one fixed feature vector, over every binary secret. It does not prove an
attack on the masked tape, rule out approximate randomized simulations, or
rule out other ordinary-LWE reductions or FHE constructions. BGK11 remains
a valid polynomial-KDM PKE result; the checked obstruction explains why its
static feature expansion does not automatically supply the required GSW
control interface. Future work should attack the masked joint-view reduction
directly or provide a different proved refresh interface, rather than iterate
this exact affine feature-closure construction.

The security statement still required
------------------------------------
One sufficient target is pseudorandomness of fresh ordinary LWE challenges
conditioned on the REAL, complete same-key GSW tape and the public key, all
under the same sampled secret. Another possible route is a joint real-to-zero
tape replacement followed by an ordinary-LWE challenge hop. Neither route
has been established here.

The proof must keep all n*(n+1)*w rows, auxiliary information, and all fresh
challenges in one view. Separate security of each product or each ciphertext
does not establish this joint claim. Binary-secret LWE itself must also be
reduced to the intended ordinary-LWE parameters; an arbitrary secret sampler
in the affine theorem is not that reduction.

First concrete security experiment to attack
--------------------------------------------
For the public-key construction, a sufficient first security goal can retain
all real controls rather than trying to replace them by uniform. Draw s,
the full same-key control tape BK(s), and independent public-key masks A.
Compare these two complete public views:

  real:   (BK(s), A, <s,A> + e);
  random: (BK(s), A, u), with independent uniform u.

BK(s) includes every gadget column of every encryption of s_i, with its
actual sampled errors. It is identical in distribution in the two games.
A is the full m-column public-key mask table; e is independently sampled
with the intended ordinary-LWE-compatible noise law. The target is one
reduction from a distinguisher for this entire experiment to ordinary LWE,
with explicit dimension, sample count, noise transformation, and cost.
Proving pseudorandomness of the control tape itself would be stronger than
needed for this particular route. A search-to-decision theorem for an already
hinted source also does not supply the ordinary-LWE-to-source reduction.

Once this game is reduced, the random public-key branch is independent of
the controls. Public binary subset-sum encryption then admits the standard
leftover-hash route. Its quantitative loss for all ciphertext columns and
polynomially many adaptive encryptions must still be proved; this paragraph
states a proposed sequence of obligations, not a proved security theorem.

Binary secrets simplify the linear/diagonal part, and the checked public
bit-flip transformation provides a zero-flooding randomization ingredient
for the remaining quadratic view. These are reasons to begin with LWE-GSW,
not evidence that its quadratic search hardness follows from ordinary LWE.
Any candidate simulator must preserve the joint noisy masking. Granting raw
products or hiding the missing source theorem in a hardness certificate
would violate the ordinary-LWE-only endpoint.

First entropy filter: exact quadratic leakage fails
--------------------------------------------------
If a proposed proof gives the adversary s*s^T as exact free leakage, the
diagonal reveals s. Removing the diagonal does not repair the route: if at
least two bits are one, s_i is one exactly when there is some j != i with
s_i*s_j = 1. Thus the off-diagonal products also recover the entire secret.

For uniform binary s, the only shared off-diagonal leakage fiber consists of
the all-zero vector and the n weight-one vectors. Every vector of weight at
least two has a singleton fiber. Consequently optimal guessing from exact
off-diagonal leakage succeeds with probability (2^n - n)/2^n. The average
conditional secret min-entropy is log2(2^n/(2^n-n)), not a linear amount of
remaining entropy. This counts exact leakage only; it is NOT an attack on
the masked GSW ciphertexts.

The recent general-distribution theorem is therefore a research tool, not a
ready-made security proof. A useful application must preserve the actual
noisy masking instead of granting raw products. Merely folding the weighted
products into a generalized secret-error distribution also requires checking
the resulting support/norm bounds: large gadget weights cannot silently be
treated as narrow encryption errors.

Second filter: narrow-noise full tapes cannot be statistically uniform
--------------------------------------------------------------------
Let m = n*(n+1)*w and suppose every error coordinate belongs to an integer
interval [-B,B], with 2B+1 < q. For each fixed normalized public mask matrix,
there are at most 2^n*(2B+1)^m possible output vectors: choose the binary
secret and then its error vector. Consequently, compared with a completely
uniform mask/output transcript, the total variation distance is at least

  1 - 2^n * ((2B+1)/q)^m.

This follows by taking the real support as a distinguishing event. The bound
also holds for correlated errors. If the bound on all errors only holds with
probability 1-epsilon, subtract epsilon from the displayed lower bound.
For a long tape and narrow errors this distance is close to one. This rules
out a statistical full-tape-to-uniform proof in that regime; it does NOT
rule out computational pseudorandomness or a computational real-to-zero
tape reduction. The inequality is an analytic support-count argument recorded
here, not yet a Lean theorem in the new modules.

Audit of the matrix-GSW circular-security claim
---------------------------------------------
Zhao et al. (2018), Section 4, Theorem 1, deserves scrutiny because it claims
a sufficient condition for circular security. Its algebra uses a solution
M' to -S'*M' = M*(-S') and defines

  Atilde = A*(R+R_ij) - M'*(g^T tensor I_n);
  Etilde = E*(R+R_ij).

That rewrite is not yet the ordinary-LWE reduction required here. A solution
M' may depend on S', so its existence alone does not give a public simulator.
The joint law of the transformed masks and errors, including the original
public key B and all P_ij, still needs justification. LWE implies
computational pseudorandomness under a specified distribution; writing an
expression in LWE-shaped notation does not make it literally uniform.
The proposed rejection sampling also needs an acceptance bound and a
hardness argument for the resulting conditioned key law. Finally, one must
identify the theorem's function f_M(S) with the entire actual refresh tape,
rather than with just a secret-dependent public-key component.

These are unresolved proof obligations from an initial reading, not a
verified attack or a proof that the claimed construction is impossible.
Primary source: https://doi.org/10.1155/2018/6362010

Further proof obligations before adopting that route
---------------------------------------------------
1. Instantiate the exact generalized-distribution or leakage game, including
   efficient sampling of every required conditional distribution. Do not
   identify an informal entropy estimate with a completed reduction.
2. Establish decisional pseudorandomness in the required joint view. The
   downloaded PKC 2026 version of BJTW proves search hardness; its quadratic
   leakage applications do not alone supply this step.
3. Verify its sample-count, support, norm, modulus, and additional hardness
   conditions for the FULL GSW tape. Particularly small-error sample regimes
   cannot automatically be extrapolated to n*(n+1)*w rows.
4. Combine those security parameters with an actual GSW refresh algorithm.
   The output must decrypt correctly AND fall back within the input noise
   budget of another refresh under the same key. Security obtained only by
   making the encryption noise essentially uniform does not meet this goal.

Shared-public-key encryption masking and the retained-tape hop, 2026-10-07
----------------------------------------------------------------------
The positive security step is to finish the public encryption argument without
assuming away the actual same-key bootstrap tape. Probability/SeededProductTV
retains a seed sampled once and proves that the joint TV distance equals the
average conditional TV distance. Independent output coordinates under that
same seed therefore cost at most the sum of their one-coordinate distances.
This proves the repeated-output leftover-hash bound; independently resampling
the public key for different ciphertext columns would describe a different
scheme and is not used.

LWE/GSWMasking identifies each stored public-key column with one group element
in (ZMod Q)^(n+1). Binary subset summation is two-universal over this group,
including composite Q. The actual stored matrix encryptor is exactly the
columnwise hash core plus the bit gadget. Its uniform selector tape is proved
equal to the actual GSWSampling.encryptInputs sampler for one challenge input
by a public transpose/reindexing bijection, independent of every secret.
The operational experiment generates the one actual key material, exposes
only its public key and all controls, allows messages chosen after both have
been seen, encrypts with the existing code, and asks for the hidden-bit guess.
Its mathematical public-view experiment has exactly that output law.

The explicit real/hybrid views are:

  real:    (ordinary PK_s, complete BK_s);
  hybrid:  (independent uniform public-key table U, complete BK_s).

The hybrid retains the exact real marginal distribution of every bootstrap
control. It changes the correlations between those controls and the ordinary
public key; that change is charged to keyReplacementAdvantage. No theorem
asserts that this term is negligible. A standard ordinary-LWE challenger does
not provide its hidden secret, so running the honest BK_s generator is not yet
a reduction producing this auxiliary information. Public-key IND-CPA without
this tape, or a secret-dependent mask permutation, does not discharge the hop.

For arbitrary retained context and arbitrary adaptive message choice, the
uniform-key branch has winning probability within

  epsilon_mask = columns * sqrt(Q^(n+1) / 2^samples) / 2

of 1/2. A uniform full-matrix core makes the bit-gadget shift a permutation,
so the terminal game wins with probability exactly 1/2. Statistical processing
and averaging over the real bootstrap context add no factor. The actual real
game therefore satisfies

  |Pr[win_real] - 1/2| <= keyReplacementAdvantage + epsilon_mask.

For the existing correctness family, Q=(64*(n+1))^16, levels=16 and
samples=256*(n+1)^2. The checked cardinality margin is

  Q^(n+1) * 2^(2*n) <= 2^samples.

It yields epsilon_mask <= 16*(n+1)*2^(-n), and a negligible whole-matrix
masking bound for every dimension, including zero. These parameters are the
previous correctness family; no larger noise or new computational assumption
is introduced to obtain this masking result.

This closes a public-encryption statistical obligation, not the computational
source gap. The full ordinary-LWE-only single-key FHE objective remains open.
The decisive next research task is a polynomial-time public reduction for the
complete real/hybrid public view above, or a different same-key bootstrap
construction whose full public view admits such a reduction. The existing
binary-secret bridge, strict random-bit implementation, arithmetic/evaluator
bit-cost bounds and serialization obligations also remain open. The IND-CPA
game here is a single challenge; no adaptive encryption-oracle extension is
claimed by this new module.

BGK/GKPV applicability audit and bounded fair-bit noise, 2026-10-07
----------------------------------------------------------------
The security assumption remains ordinary LWE alone. BGK11 is relevant because
its polynomial-KDM construction derives its security from an ordinary-LWE
instance instead of positing circular security. However, its Section 6 does
not instantiate the present GSW construction without another argument.

Its underlying ACPS decryption secret is an expanded monomial vector gamma(x),
although the client can store just x. Functions of degree at most d in x are
affine in the degree-d monomial vector. In a GSW control encrypting an original
bit, multiplying that bit by a degree-d decryption feature produces degree
d+1; controlling by a degree-d feature can produce degree 2d. This is exactly
the missing feature-span closure that the existing GSWFeatureClosure module
checks for the fixed exact-affine route. A theorem about polynomial-KDM ACPS
ciphertexts cannot be transferred merely by choosing GSW messages with the
same polynomial descriptions. A different ciphertext compiler could still be
worth investigating; this audit is not an impossibility result for FHE.

BGK11 Theorems 1.3 and 6.4 require a superpolynomial prime p, modulus q=p^2,
and negligible source-to-target Gaussian width ratio beta/sigma. Their
entropy-LWE reduction cites GKPV09, published as GKPV10, Robustness of the
Learning with Errors Assumption. Its low-rank noisy matrix replacement needs
the correlated error Z*s to be absorbed by a larger target error law, as well
as enough residual entropy for extraction. The current polynomial coefficient
modulus (64*(n+1))^16 and current error family do not instantiate these stated
hypotheses. Superpolynomial modulus magnitude is not itself a polynomial-bit
length violation; changing parameters is possible but would require new
correctness, sampling and security arguments. The full joint bootstrap view
also needs to meet the actual leakage/entropy hypotheses, not only a bound on
one row or the entropy of the original secret before the view is published.

The positive implementation step is Probability/BoundedUniform. An explicit
public bijection combines fair bits into a uniform word in Fin(2^width).
CoinBound checks structurally that every query has index 1 (a fair bit) and
that every execution path fits its budget. For W>0 the ticket width is
floor(log2 W)+1, so W<2^width<=2*W. Rejection accepts a valid ticket or tries
again, up to a specified number of rounds; exhaustion returns valid ticket 0.
This width choice is essential: padding each attempt with the whole security
parameter could make the acceptance probability exponentially small.

The one-step ideal continuation is proved exactly uniform. Averaging the TV
of the two continuations charges only the rejected words, with rate at most
1/2. Induction proves TV(sampleFin W rounds, uniform Fin W)<=2^(-rounds),
and a structural budget of rounds*ticketWidth W. The finite enumeration in
the proof does not allocate a ticket table in the executable implementation.

Probability/WeightedBitSampler maps those tickets through the original
compressed subtraction scan. Its statistical distance from the old abstract
uniform-ticket sampler is at most 2^(-rounds). Every selected outcome satisfies
all stored-outcome invariants, even on exhaustion: the fallback is a valid
ticket, not the compressed table's potentially invalid outcome fallback.
A left-inverse proof for the Option.some embedding shows that this ProbComp
TV bound is also the full PMF etvDist bound. Gaussian comparison therefore adds
only the bounded-ticket error, without a modulus-size factor.

With rounds=(n+1)^2, each scalar uses at most

  (n+1)^2 * (3*(n+1)^2+1)

primitive fair bits. Its added TV loss is <=2^(-n), hence negligible.
LWE/GSWBitSampling supplies an operational one-key generator using that noise
sampler. Its full key material, including the original secret and all public
and control correlations, differs from the previous Gaussian reference by at
most

  272*(n+1)^2*2^(-n) + previous_Gaussian_comparison_bound.

That loss is proved negligible. The original bounded error support is
preserved, so the whole-circuit correctness failure is exactly zero for every
positive dimension, for any well-formed circuit program in the existing
model. The dimension-zero case is bounded separately to prove whole-family
negligible failure as well. No circuit-depth multiplier appears in the
key-law replacement.

New checked model: LWE/GSWLinkedMask formalizes a concrete full-matrix seed
variant of independent masking and public linking. It is not claimed to be a
formalization of the paper's entire multi-key protocol. Write rows=n+1,
columns=rows*levels, let D_i be independent uniform full ciphertext matrices,
let r_i be independent uniform bits, and form

  P = sum_i r_i D_i + mu G,
  Z = sum_i Enc_pk(r_i) DigitDecomp(D_i),
  C = P - Z.

The module proves TV((D,P),(D,U)) <=

  sqrt(Q^(rows*columns)/2^pads)/2.

The statement retains an arbitrary earlier key/context and allows mu G to
depend on that context, as long as the later masks are independent. It
expressly omits the encrypted-pad tape. An ordinary-LWE proof must account for
that tape, or the published link itself, in the adversary's actual view.

The exact phase cancellation gives control noise

  -sum_i Noise(Enc_pk(r_i),r_i) DigitDecomp(D_i).

If each encrypted pad has error at most B, the resulting control error is at
most pads*growth*B. For public pad encryptions with samples LWE columns and
public-key phase errors at most E, this becomes pads*growth*samples*E. No
independence of those errors is assumed for correctness.

More specifically, public encryption Enc_pk(r_i)=PK*S_i+r_i G gives the exact
public identity

  C = mu G - PK*(sum_i S_i DigitDecomp(D_i)).

The private mask bits cancel from this expression, but mu still depends on
the same key when it is a bootstrapping control. A same-key bit control at a
mask gadget column still has phase -s_i*s_j*g_level plus the exact linked
error. This is a new way to obtain a correlated GSW control; its standalone
masking bound does not prove the security of the public result.

The coefficient law of sum_i S_i DigitDecomp(D_i), jointly with D, encrypted
pads, masked hints and all other key material, is now an explicit reduction
target. Proving it uniform marginally would not permit replacing PK by
uniform while retaining a hidden-key-dependent hint. A valid ordinary-LWE
simulator needs a challenge embedding that also produces the linked material
with the correct joint law. Noise amplification must simultaneously fit a
parameter family permitting repeatable refresh. The new generic bound has
not been instantiated with the existing asymptotic bootstrap family.

Receiver-readable tensor links: disclosure audit, 2026-10-08
-----------------------------------------------------------
This continuation makes progress by checking a claimed ordinary-LWE candidate
against its complete published view. It does not construct the requested
one-key FHE and does not replace the ordinary-LWE-only requirement.

Primary source: WHT26, https://link.springer.com/article/10.1186/s42400-025-00431-z .
The construction publishes P_j and Z_j to permit offline extension. Its own
linking equations imply t*(P_j-Z_j)=t*⊗t_j⊗g plus bounded error. KeyGen fixes a
unit component in t*. A participant knowing t* can therefore compute the
entire vector of noisy gadget multiples of every t_j coordinate. The paper's
written security game omits this published linking material. The following
recovery analysis is ours. It applies to a receiver-owned-key view; it does
not infer an attack against an unknown one-key specialization.

For q=2^ell, suppose readable observations satisfy

  y_j = a*2^j + e_j mod q,  j=0,...,ell-1,
  |centered(e_j)| <= B < q/4.

Start with knownLow=0. At bit k read level j=ell-k-1 and subtract
knownLow*2^j. If knownLow=a mod 2^k, the remaining signal is the k-th bit of a
times q/2. Nearest-codeword decoding at {0,q/2} recovers that bit. Add its
weight 2^k and continue. This recovers the complete residue a in ell steps,
including arbitrary negative secret coordinates represented modulo q. It
does not enumerate q candidates or require a bound on |a|. Applying it to
all sender coordinates gives an efficient receiver-side recovery algorithm.
A scalar diagnostic recovered all 2,044 residues for ell=2,...,10 with signed
noise up to q/4-1, plus 400 random residues up to a 256-bit modulus.

LWE/NoisyBinaryGadget proves the modular remainder update, exact residual-bit
identity, induction for every recovered low-bit prefix, the half-modulus
separation, and complete recovery under the quarter-modulus margin. The
implemented decoder receives only observations. It has no secret/error input.

LWE/GSWLinkedDisclosure models the exact tensor layout with n rows and
n*n*ell columns. Its sourceLink computes the nonzero columns of the sparse
Modified LinkAlgo products using the already proved GSW decomposition. The
exact phase equals the subset-mask phase plus the selected pad-encryption
errors. Sparsity gives a bound

  B_link <= m * growth(params,n) * beta.

For base 2, growth=n*ell. The published m*n^3*ell^2*beta bound is looser.
The recovery proof is instantiated with the project's actual public pad
sampler: beta=publicSamples*publicKeyError. It then proves decryption of an
actual fresh public GSW challenge of either bit, using the recovered sender
vector and the usual fresh-challenge separation margin. This is a deterministic
conditional attack theorem, not a claimed formalization of the paper's full
asymptotic security game or Gaussian experiment.

The attacker-facing interface uses StoredHint vectors and a stored challenge.
Hint materialization and vector access are proved to agree with the matrix
model. recoverStoredSender and decodeStoredChallenge take only P,Z, the
challenge data, and the receiver's existing key. No sender-dependent closure,
subset bits, encrypted-pad coins or sender secret is an attack input.

Recursive-mask vector ciphertexts: an explicit quadratic-KDM reduction, 2026-10-08
--------------------------------------------------------------------------------
This step constructs and checks a complete fixed-batch security reduction for
one candidate ciphertext law. It is a component toward the ordinary-LWE-only,
one-secret-key FHE objective, not its completion. No independent quadratic-KDM,
block-binary LWE, circular-security or RLWE hardness assumption is introduced.

The recursive-mask idea is motivated by Brakerski--Vaikuntanathan's CRYPTO 2011
paper, Fully Homomorphic Encryption from Ring-LWE and Security for Key Dependent
Messages, Section 4 and its preceding overview. The source itself uses RLWE and
explicitly distinguishes ring-element KDM from the bitwise key representation
needed for bootstrapping. It is stored as ../refs/kdm/BV11KDM.pdf (20 pages),
from https://www.wisdom.weizmann.ac.il/~zvikab/localpapers/IdealHom.pdf .
It is distinct from the FOCS standard-LWE paper already catalogued as BV11.
The checked vector specialization and its reduction below are our analysis;
no novelty/priority claim is made.

For a column-vector secret s with n coordinates, use independent uniform
A in R^(n*n), a in R^n, and independent scalar errors e_i,f. For a privately
computed message w, publish the recursive ciphertext

  T=A,  c=A^T*s-a+e,  b=a^T*s+w+f.

The decryption expression is b+c^T*s-s^T*T*s. Its exact value is w+f+e^T*s.
Thus errors bounded by B and centered secret coordinates bounded by S give
error at most (n*S+1)*B. Binary secrets give (n+1)*B. The bound still needs
an appropriate decoding margin; it does not make a uniform-modulus secret
usable for low-noise decryption.

Fix each polynomial message w=s^T*M*s+l^T*s+o using public M,l,o. Given
ordinary fresh LWE rows (A', y=A'^T*s+e) and (a', z=a'^T*s+f), the public
simulator outputs

  T=A'-M,  c=y-a'+l,  b=z+o.

This algorithm has no secret input. The variable change A=A'-M and
a=a'-M^T*s-l proves equality with the honest encryption law. It is a
bijection of the full mask tape for every fixed s. Unlike the secret-dependent
normalization of GSW columns, the actual challenge-to-view transformation is
public: it shifts a known matrix coefficient and combines available LWE rows.

The reduction handles all messages simultaneously and retains p additional
ordinary LWE rows as the same-key public-key batch. Its ordinary source has
p+k*(n+1) rows for k messages; each recursive ciphertext has n*n+n+1 ring
coordinates. An explicit sum/product/option enumeration identifies those rows
with Fin of the stated count. Real-view and uniform-view distribution equalities
are proved. A bijection on the full public source tape shows that the ideal
retained view is independent of M,l,o. Consequently the real-versus-ideal
advantage equals exactly one ordinary-LWE advantage for the public reduction;
fixed polynomial messages versus another fixed batch (including zero) have
a bound of two such advantages.

RecursiveQuadratic also composes the small block-binary secret specialization
with BlockBinaryReduction.advantage_le_combined_ordinaryLWE_add_jointGap.
The resulting bound contains only explicit ordinary uniform-secret narrow- and
wide-error LWE advantages plus the existing joint statistical gap. It does not
assume block-binary hardness separately. The gap's negligibility, the concrete
noise laws, efficient sampling and an appropriate parameter family still need
to be instantiated before claiming asymptotic cryptographic security. The
reduction is for fixed nonadaptive message batches; no adaptive KDM oracle is
being formalized here.

The ciphertext-law boundary is essential. These are fresh private recursive
ciphertexts, not GSW columns and not a public encryption algorithm. Dropping T
would leave an additional s^T*T*s term in the linear decryption phase. Using
quadratic features as an extended GSW secret introduces cubic phase messages
when encrypting an original secret bit. No conversion to the existing scalar
GSW controls, closed multiplication/relinearization interface, or reusable
refresh algorithm has been established. A compatible public encryption and
complete-view proof with that interface remain necessary for the full FHE goal.

The next constructive step is to retain this explicit source reduction while
seeking a ciphertext evaluation/refresh interface that does not increase the
secret-feature degree after every refresh. The existing affine feature-closure
barrier prevents treating simple monomial expansion as that missing compiler.

Checked interval-noise component (2026-10-08; not a complete FHE theorem):
UniformInterval uses a uniform ticket in Fin (2*B+1), shifted by -B and
cast modulo q. A cyclic coupling has one exceptional ticket, proving unit-shift
TV at most 1/(2*B+1). The resulting arbitrary-shift bound is

  TV(shift_t(W), W) <= |centered(t)|/(2*B+1).

It holds for every positive coefficient modulus q, without an injectivity or
no-wrap premise. All mapped tickets have centered absolute value at most B.
If a total narrow-error law N has centered first moment mu, the convolution
bound is TV(N+W,W) <= mu/(2*B+1). The exact first moment is a finite sum, not
an additional security assumption. The actual finite-budget sampler W_r uses
at most r*ticketWidth(2*B+1) fair bits, remains in the same bounded support,
and has TV(W_r,W) <= 2^(-r). For B=2^lambda, ticketWidth <= lambda+2.
The checked sampled-convolution bound is

  TV(N+W_r,W) <= mu/(2*B+1) + 2^(-r).

NoiseFlooding defines the public transformation (A,y) -> (A,y+extra), with
independent IID extra errors and no secret input. Its real branch is ordinary
LWE with the exact scalar convolution N+extra; its uniform branch is preserved.
For m rows, wide interval ordinary LWE therefore has advantage at most the
narrow ordinary-LWE advantage of this explicit reduction plus

  m*(mu/(2*B+1) + 2^(-r)).

RecursiveQuadratic.interval_advantage_le_narrowLWE composes this operation
with the existing complete-view quadratic reduction and block-secret extraction.
Let n=blockCount*blockLength, d be the extracted ordinary-LWE dimension,
m=p+k*(n+1) be the full source-row count (including the p retained public-key
rows), and ell=blockLength. The concrete real-versus-common-ideal bound is

  2*sum_{i<n} Adv_LWE_N(rowHybrid_i)
  + min(1, (m*n/(ell+1))*mu/(2*B+1))
  + sqrt((q^d-1)/(ell+1)^blockCount)/2
  + Adv_LWE_N(floodedExtractedReduction)
  + m*(mu/(2*B+1) + 2^(-r)).

Every computational term has a uniform secret and the same narrow error law N.
The compiled reductions are explicit; there is no separate wide-error,
block-binary, quadratic-KDM or circular hardness premise in this bound.
It is a concrete fixed-batch component theorem. Polynomial reduction running
time, negligibility for a selected parameter family, Gaussian-law comparison,
and the missing FHE compiler/refresh interface still need to be discharged.
A fair-bit query bound is not a formal bound on all arithmetic running time.
The honest recursive view in this theorem still uses the exact wide law; using
the finite-budget law for the whole honest view requires accounting for every
original wide-error draw, including the retained public-key rows.

Checked recursive-component parameter family (2026-10-08):
RecursiveQuadraticParameters now instantiates the earlier proposed scaling,
using t=lambda+1 to avoid zero-width and zero-dimension corner cases:

  ordinary source dimension d=t^3,
  binary target dimension n=2*t^5 (block length one),
  coefficient modulus q=2^(t^2),
  narrow Gaussian width t^2,
  narrow cutoff, precision and retry count t^4,
  wide interval radius B=2^t, flooding retry count t^2.

The source modulus has ticket width at most t^2+1, so its value being
exponential does not require exponential word length. The compiled narrow
Gaussian sampler uses at most t^4*(3*t^4+1) fair bits and has centered first

  (m*(t^9+2*t^4)+1)*2^(-lambda).

Here m=p+k*(n+1) includes every error in the retained p-row public-key batch

Fixed-format evaluation and the next security target, 2026-10-08
---------------------------------------------------------------
RecursiveMultiplication proves two concrete scalar phase products. The first
multiplies two linear phases without any auxiliary hint: for phases b1+c1*s
and b2+c2*s, output T=-outer(c1,c2), c=b2*c1+b1*c2 and b=b1*b2. Its recursive
phase is their exact product. The second publicly relinearizes arbitrary
recursive phases using an explicitly defined hint table. Index decryption
features by none (one), some(inl i) (s_i) and some(inr(i,j)) (s_i*s_j), with
N=n*n+n+1 features. The corresponding public ciphertext coefficients are
b, c_i and -T_ij. The table entries have plaintext

  gadget(level)*feature(s,left)*feature(s,right).

There are N^2*levels entries. Decompose each public coefficient product into
short base digits and sum digit-weighted table ciphertexts. The exact output
phase is the input-phase product plus the sum of digit-weighted hint errors.
For a uniform hint error bound H, that extra error is at most
N^2*levels*(base-1)*H. Actual private generation under the single binary secret
has hint errors at most (n+1)*B for bounded scalar errors B. The full plaintext
product error is m1*e2+m2*e1+e1*e2 plus this relinearization error, with a checked
centered-magnitude bound. This is raw phase arithmetic, not direct multiplication
of the previous half-modulus Boolean encoding or a bootstrap theorem.

The table includes gadget multiples of s_i*s_j*s_k*s_l. Four Boolean cube
differences prove that a weight-one entry with four distinct coordinates cannot
be a quadratic polynomial, even on the binary-secret corners. Therefore the
existing fixed quadratic-message ordinary-LWE theorem does not prove security
of this publication. No degree-four KDM assumption is adopted; the table is an
alternative algebraic interface with a precisely identified unproved security
obligation, not a replacement for the ordinary-LWE-only objective.

A more direct evaluation interface is now formalized in RecursiveFeatureGSW.
A public, computable finite enumeration maps recursive coefficient triples
bijectively to vectors of length N. The derived vector gamma(s)=(1,s_i,s_i*s_j)
uses the original secret only. Decryption is the gamma/coefficient pairing.
Flattening each column gives a rectangular GSW matrix; unflattening is inverse
for every matrix. Applying the existing public GSW gadget/digit multiplication
and unflattening keeps exactly the same column format. It needs no quartic
relinearization table and draws no new secret. Its exact error is

  error1*digitMatrix(ciphertext2) + message1*error2.

The bit-product bound is N*levels*(base-1)*E1+E2. The public NAND and the
nearest-codeword decoder at the constant feature's selected gadget column have
checked correctness from this bound and the explicit public separation margin.
These representation and evaluation definitions are computable; full arithmetic
cost and final parameter instantiations are not yet proved. Security of the
native scalar-secret GSW key sampler cannot be transferred to this derived key
by its algebraic form alone. No LWE hardness premise for gamma is asserted.

There is a checked incompatibility with the previous public encryption.
Its Regev embedding has T=0, so every quadratic flattened mask coordinate is
zero. Adding bit*gadget then reveals the bit in a quadratic diagonal gadget
entry at level zero. A public-coordinate observer recovers it for every raw
linear ciphertext choice in a nontrivial modulus ring, without any secret input.
Thus the previous linear public key cannot serve as the full mask for this GSW
representation. The next constructive security step is to sample full recursive
zero-ciphertext public columns, retain their entire law through the existing
ordinary-LWE reduction, and prove the uniform full-coordinate subset-mask law.
This is a specific algorithm/distribution proof to implement, not a new assumption.
